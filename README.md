# مشروع الكومبايلر

تصميم المترجمات، كلية الحاسبات والمعلومات جامعة المنوفية
م. محمد شهاب

## إيه ده

مشروع المادة مقسوم أجزاء. كل جزء بيبني حتة من الكومبايلر، وفي الآخر
بيبقى معاك المشروع كامل وانت كاتبه بإيدك.

| | الجزء | اللي بتكتبه |
|---|---|---|
| **01** | **الـ lexer** | التعبيرات اللي بتقطّع الكود لـ tokens |
| 02 | جدول الرموز | تجميع الأسماء وأماكنها |
| 03 | الجرامر | الأسبقية مكتوبة كقواعد |
| 04 | الـ parser | تركيب الجملة |
| 05 | الـ atoms | الكود الوسيط |
| 06 | التنفيذ | تشغيل البرنامج فعلاً |

كل جزء بينزل في وقته. اللي موجود دلوقتي هو 01.

## السلايدز

`slides/JavaCC.pptx` فيه سلايدات السكشن، نفس اللي اتعرض قدامكم.

## محتاج JDK

مش JRE. لازم JDK عشان فيه `javac`.

نزّله من https://adoptium.net واختار Temurin JDK 21.

وبعد ما تركّبه اقفل أي نافذة terminal مفتوحة وافتحها من الأول، وإلا الجهاز
لسه مش شايفه. للتأكد اكتب `javac -version` ولازم يرد برقم.

ومش محتاج تنزّل JavaCC. هو موجود في الريبو، ملف `javacc.jar` في الروت.
متمسحوش.

## التشغيل

ادخل مجلد الجزء اللي شغال عليه:

| | |
|---|---|
| ويندوز | دبل كليك على `run.bat` |
| ماك ولينكس | `./run.sh` |

كل اللي بيتولّد بيروح في مجلد `build` جوه الجزء، فمجلدك يفضل نضيف. ولو
الدنيا اتلخبطت امسح `build` وشغّل تاني.

## الملفين اللي يهموك

جوه مجلد كل جزء:

| | |
|---|---|
| **`Lexer.jj`** | ده اللي بتكتب فيه، وده اللي بتسلّمه. فيه أماكن فاضية متعلّمة من ١ لـ ٦ |
| **`test.txt`** | كود الـ Java اللي بتجرّب عليه. الأداة بتقرا الملف ده وتقطّعه |

`test.txt` فيه دلوقتي:

```java
int x = 42;
float rate = 3.14;
String msg = "Hello World";
for (i = 0; i < 10; i++) { total += i; }
```

امسحه وغيّره زي ما انت عايز. كل ما تخلّص قاعدة حط سطر يختبرها وشغّل.

والباقي: `run.bat` و `run.sh` للتشغيل، و `javacc.jar` الأداة، و `build`
اللي بيتولّد ومتعدّلش فيه ومتسلّمهوش.

وفي كل مجلد ملف `README.md` فيه تفاصيل الجزء وأسئلته.

## التلات أوامر

السكريبت بيطبعهم قدامك عشان تعرف انت عملت إيه:

```
java -cp ../javacc.jar javacc -OUTPUT_DIRECTORY=build Lexer.jj
javac -d build build/*.java
java -cp build Lexer test.txt
```

الأول JavaCC بيقرا وصفك ويكتب كود Java، والتاني Java بتترجم الكود ده،
والتالت بيشغّله على ملف الاختبار.

ولو حابب تشغّلهم بإيدك واحد واحد بدل السكريبت، دول هما.

## التسليم

اللي بتسلّمه هو ملف الـ `.jj` بتاعك وبس. مجلد `build` مبيتسلّمش، ده كود
مولّد انت مكتبتش منه حرف.
